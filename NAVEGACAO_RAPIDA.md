## 📋 Checklist de Aprendizado

### Nível 1: Fundamentos ✅
- [ ] Sou capaz de criar um programa Java simples
- [ ] Entendo variáveis, tipos de dados e operadores
- [ ] Consigo usar estruturas de controle (if, for, while)
- [ ] Sei trabalhar com arrays
- [ ] Posso criar classes e objetos básicos

### Nível 2: Intermediário ✅
- [ ] Entendo encapsulamento e modificadores de acesso
- [ ] Consigo implementar herança e polimorfismo
- [ ] Sei usar interfaces e classes abstratas
- [ ] Entendo coleções (List, Set, Map)
- [ ] Posso tratar exceções apropriadamente

### Nível 3: Avançado ✅
- [ ] Domino Generics e Type Parameters
- [ ] Consigo usar Streams API de forma eficaz
- [ ] Entendo expressões Lambda e interfaces funcionais
- [ ] Posso trabalhar com Threads e sincronização
- [ ] Sei usar Enums e Optional

### Nível 4: Especialista ✅
- [ ] Implemento arquiteturas complexas com OOP
- [ ] Optimizo performance com Streams
- [ ] Domino concorrência avançada
- [ ] Consigo debugar e resolver problemas complexos
- [ ] Contribuo com padrões e boas práticas

## 💻 Como Executar os Exemplos

```bash
# 1. Compilar todo o projeto
mvn clean compile

# 2. Executar uma classe específica
mvn exec:java -Dexec.mainClass="com.example.MainClassName"

# 3. Rodar testes
mvn test

# 4. Empacotar
mvn package
```

## 📌 Dicas Importantes

### ✅ Para Aprender Melhor:
1. Leia a documentação inteira de um tópico
2. Execute todos os exemplos de código
3. Modifique os exemplos e teste diferentes valores
4. Implemente seus próprios exemplos
5. Revise o código-fonte do projeto

### ⚠️ Erros Comuns:
- Confundir compilação com execução
- Não entender referências vs valores
- Ignorar tratamento de exceções
- Não usar encapsulamento adequado
- Misturar conceitos de Streams com loops tradicionais
